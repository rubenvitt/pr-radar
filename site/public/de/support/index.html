Support

Fragen, Fehler, Ideen – schreib uns. Wir antworten meist innerhalb weniger Werktage, auf Deutsch oder Englisch.

Kontakt

E-Mail: pr-radar@rubeen.dev

Fehler und Wünsche kannst du auch als GitHub-Issue melden. Issues dort sind öffentlich.

Was uns beim Helfen hilft

  • App und Version: auf dem Mac unter PR Radar → Über PR Radar, auf iPhone und iPad unter Einstellungen → Info
  • Deine macOS- oder iOS-Version
  • Was du getan hast, was du erwartet hast und was stattdessen passiert ist
  • Auf dem Mac: die Protokolldatei über Hilfe → Protokoll im Finder zeigen. Sie enthält keine Tokens, kann aber Repository-Namen enthalten.

Schick uns niemals deinen GitHub-Token. Wir fragen nie danach.

Häufige Fragen

Welche Rechte braucht mein GitHub-Token?

Einen Fine-grained Personal Access Token für die gewünschten Repositories mit Metadata, Contents, Commit statuses und Actions/Checks (lesen) sowie Pull requests (schreiben, nötig für Merge und Auto-Merge). Erlaubt deine Organisation keine Fine-grained Tokens, nimm einen klassischen Token mit repo oder die GitHub CLI.

Woher nimmt die Mac-App meinen Token?

Aus den Umgebungsvariablen GITHUB_TOKEN oder GH_TOKEN, sonst aus der GitHub CLI (gh auth token). Das klappt auch beim Start aus dem Finder. Der Token verlässt deinen Mac nur in Anfragen an GitHub.

Warum lässt sich Auto-Merge nicht einschalten?

Auto-Merge muss im Repository erlaubt sein (Settings → General → Allow auto-merge) und greift nur, wenn der Ziel-Branch Branch Protection oder ein Ruleset mit Pflicht-Checks oder Reviews hat.

Eine Merge-Methode fehlt.

PR Radar bietet nur Methoden an, die sowohl die Repo-Einstellungen als auch die Rulesets des Ziel-Branches erlauben. Verlangt ein Ruleset zum Beispiel Squash-Merges, fehlt „Merge-Commit“.

Ein Repository zeigt „nur lesend“.

Dein Token darf das Repository lesen, aber keine Pull Requests schreiben. Gib dem Token für dieses Repository Pull requests: write oder bitte eine Person mit Owner-Rechten in der Organisation, den Token freizugeben.

PR Radar meldet, dass das API-Kontingent aufgebraucht ist.

GitHub begrenzt, wie viele Anfragen ein Token pro Stunde stellen darf. PR Radar pausiert dann automatisch, bis GitHub wieder Anfragen zulässt, und macht danach von selbst weiter. Andere Werkzeuge mit demselben Token teilen sich dieses Kontingent.

Ich bekomme keine Benachrichtigungen.

Prüfe, ob Benachrichtigungen in der App eingeschaltet und für PR Radar in den Systemeinstellungen erlaubt sind. Auf iPhone und iPad entscheidet iOS, wie oft Apps im Hintergrund aktualisieren dürfen. Bei geschlossener App können Mitteilungen deshalb später kommen.

Wie entferne ich alle meine Daten?

iPhone und iPad: Entferne den Token in der App und lösche die App.

Mac: Lösche die App und die Ordner ~/Library/Application Support/pr-radar/ und ~/Library/Logs/PR Radar/. Hat die App einmal ein Ausweich-Protokoll benutzt, zeigt Hilfe → Protokoll im Finder zeigen, wo es liegt (im temporären Ordner). Die Mac-App liest den Token aus GITHUB_TOKEN, GH_TOKEN oder der GitHub CLI und speichert ihn nicht selbst. Entferne ihn also dort (zum Beispiel mit gh auth logout).

Brauchst du den Token gar nicht mehr, widerrufe ihn auf GitHub unter Settings → Developer settings → Tokens. Die Apps senden uns nichts. Wir haben nur, was du uns selbst schickst (Support-Mails), und bei Direktkäufen die Bestelldaten vom Wiederverkäufer. Möchtest du die gelöscht haben, schreib uns, siehe Datenschutzerklärung.

Wie bekomme ich mein Geld zurück?

Bei Käufen im App Store beantragst du die Erstattung bei Apple unter reportaproblem.apple.com. Bei direkt gekauften Mac-Lizenzen kümmert sich der Wiederverkäufer, der auf deiner Rechnung steht. Schreib uns, wenn du unsicher bist, wir helfen.
