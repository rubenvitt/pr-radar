Alle Pull Requests auf einem Radar.

PR Radar bündelt offene Pull Requests, Pipelines, Auto-Merge, zuletzt Gemergtes und Releases aus all deinen GitHub-Repositories in einem ruhigen Fenster – statt in zwanzig Browser-Tabs.

Was du auf einen Blick siehst

Gebaut für alle, die viele Repositories im Blick behalten: Maintainer, Plattform-Teams, Freelancer mit mehreren Kunden.

⇄

Alle offenen Pull Requests

Nach Repository gruppiert oder als eine Liste, mit Review-Status, Konflikten, Labels, Branch und Diff-Größe. Als Liste oder als Flow von den Checks bis zum Merge.

●

Pipelines live

Läuft, rot oder grün für jeden Pull Request, jeder Check einen Klick entfernt. Solange etwas läuft, aktualisiert PR Radar alle 10 Sekunden.

✓

Auto-Merge und Mergen

Auto-Merge einschalten oder direkt mergen. PR Radar bietet nur die Methoden an, die Repo-Einstellungen und Rulesets des Ziel-Branches erlauben.

≡

Alle mergen

Alle sichtbaren, sofort mergebaren Pull Requests nacheinander mergen, je Repository und Ziel-Branch. Vorübergehende Ablehnungen werden sicher wiederholt.

◷

Zuletzt gemergt und Releases

Eine Timeline nach Tagen mit allem, was gelandet ist, und die neuesten Releases aller Repositories samt Beschreibung.

🔔

Benachrichtigungen

Eine Systemmitteilung, wenn eine Pipeline rot oder grün wird oder ein Pull Request gemergt wurde. Schnellfilter für alles, was auf dich wartet.

Datenschutz von Anfang an

  • Dein GitHub-Token bleibt auf deinem Gerät.
  • Die Apps sprechen direkt mit GitHub. Es gibt keinen PR-Radar-Server dazwischen.
  • Keine Analyse, kein Tracking, keine Werbung, kein Konto.

Zur Datenschutzerklärung

Nativ auf jedem Gerät

  • Mac: eine schnelle native App in Rust, folgt Hell und Dunkel, komplett per Tastatur bedienbar.
  • iPhone und iPad: dieselben Funktionen in SwiftUI, mit Wischgesten, Dynamic Type und VoiceOver.

Verfügbarkeit

PR Radar ist kostenlos. Die erste Version ist in Vorbereitung: die Mac-App als Download von GitHub, die App für iPhone und iPad im App Store.

Signierter und notarisierter Download über GitHub Releases, mit automatischen Updates. Bald verfügbar.
