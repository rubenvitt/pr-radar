Support

Questions, bugs, ideas – open an issue on GitHub. PR Radar is a free side project, so answers can take a few days. English or German are both fine.

Contact

Open an issue on GitHub

Pick a template: bug, question or idea. You need a GitHub account, and issues are public, so leave out anything you don't want to share. Existing issues: all issues. In the apps: Help → Report a Problem… on the Mac, Settings → About → Report a Problem on iPhone and iPad.

What helps us help you

  • App and version: on the Mac under PR Radar → About PR Radar, on iPhone and iPad under Settings → About
  • Your macOS or iOS version
  • What you did, what you expected and what happened instead
  • On the Mac: the log file, via Help → Show log in Finder. It contains no tokens, but may contain repository names.

Never post your GitHub token. We will never ask for it. If you attach a log, check it first.

Frequently asked questions

Which permissions does my GitHub token need?

A fine-grained personal access token for the repositories you want to see, with Metadata, Contents, Commit statuses and Actions/Checks (read) and Pull requests (write, needed for merge and auto-merge). If your organization does not allow fine-grained tokens, use a classic token with the repo scope or the GitHub CLI.

Where does the Mac app get my token from?

From the environment variables GITHUB_TOKEN or GH_TOKEN, otherwise from the GitHub CLI (gh auth token). This also works when you start the app from the Finder. The token never leaves your Mac except in requests to GitHub.

Why can't I turn on auto-merge?

Auto-merge has to be allowed in the repository (Settings → General → Allow auto-merge) and only works when the target branch has branch protection or a ruleset with required checks or reviews.

A merge method is missing.

PR Radar only offers the methods that both the repository settings and the rulesets of the target branch allow. If, for example, a ruleset requires squash merges, “merge commit” is not offered.

A repository shows “read only”.

Your token can read the repository but not write pull requests. Give the token Pull requests: write for that repository, or ask an owner of the organization to approve the token.

PR Radar says the rate limit is used up.

GitHub limits how many requests a token may make per hour. PR Radar then pauses automatically until GitHub allows requests again and continues on its own. With many repositories, other tools using the same token share this limit.

I don't get notifications.

Check that notifications are on in the app and allowed for PR Radar in the system settings. On iPhone and iPad, iOS decides how often apps may refresh in the background, so notifications can arrive late while the app is closed.

How do I remove all my data?

iPhone and iPad: remove the token in the app and delete the app.

Mac: delete the app and the folders ~/Library/Application Support/pr-radar/ and ~/Library/Logs/PR Radar/. If the app ever used a fallback log, also delete the folder that open "$TMPDIR/pr-radar" opens in Terminal. The Mac app reads your token from GITHUB_TOKEN, GH_TOKEN or the GitHub CLI and does not store it itself, so remove it there (for example with gh auth logout).

If you no longer need the token at all, revoke it on GitHub under Settings → Developer settings → Tokens. The apps send nothing to us, so there is nothing else to delete on our side. Issues you opened on GitHub you can edit or delete there yourself, see the privacy policy.
