What you see at a glance

Built for people who look after many repositories: maintainers, platform teams, freelancers with several clients.

⇄

All open pull requests

Grouped by repository or as one list, with review state, conflicts, labels, branch and diff size. As a list or as a flow from checks to merge.

●

Pipelines live

Running, red or green for every pull request, with every check one click away. While something runs, PR Radar refreshes every 10 seconds.

✓

Auto-merge and merge

Turn auto-merge on or merge directly. PR Radar only offers the methods your repository settings and branch rulesets allow.

≡

Merge all

Merge every visible pull request that is ready, one after another per repository and target branch. Temporary refusals are retried safely.

◷

Recently merged and releases

A timeline of what landed, by day, and the latest releases of all repositories including their notes.

🔔

Notifications

A system notification when a pipeline turns red or green or a pull request is merged. Quick filters for everything waiting on you.

Private by design

  • Your GitHub token stays on your device.
  • The apps talk directly to GitHub. There is no PR Radar server in between.
  • No analytics, no tracking, no ads, no account.

Read the privacy policy

Native on every device

  • Mac: a fast native app written in Rust, follows light and dark mode, full keyboard control.
  • iPhone and iPad: the same features in SwiftUI, with swipe actions, Dynamic Type and VoiceOver.
