# Icons

Icon-Set „Material Rounded“ von [Icons8](https://icons8.com), gefüllt, 24er-Raster.
Kommerziell lizenziert über ein Icons8-Abo (keine Namensnennung nötig).

Diese Dateien stehen **nicht** unter der Lizenz des Repos (FSL-1.1-ALv2) und dürfen
nicht losgelöst von PR Radar weiterverwendet oder weitergegeben werden.

Die Dateinamen folgen den Lucide-Pfaden von GPUI Kit (`icons/<name>.svg`), damit sie
auch die Icons der eingebauten Komponenten ersetzen. Neue Icons aus demselben Stil
(icons8-Plattform `m_rounded`) ergänzen; `cargo test` meldet fehlende und ungenutzte
Dateien.
